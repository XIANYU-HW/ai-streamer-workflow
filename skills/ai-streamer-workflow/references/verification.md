# 有界验收

按当前改动验证，不把整套流程的成功作为修复小问题的先决条件。

| 层级 | 可接受证据 | 不代表 |
|---|---|---|
| 安装 | 干净目录 setup 与依赖检查、独立空白数据目录 | 任何真实 Agent 或直播能力 |
| 岗位 | 宿主工具返回的真实会话/运行回执 | 模型已配置付费接口 |
| 核心模拟 | 有限 demo 明确 simulated、租约/去重/停止测试 | 游戏实际运动、观众收看 |
| 游戏 | 实际游戏画面/状态随模型决策改变，输入可释放 | 仅调用成功/输入数量不够 |
| 音频 | 两主播声音分别进入所选节目软件，保存片段有可听输出 | TTS生成/扬声器听见不够 |
| 互动 | 真实事件接收、礼物去重和到开口延迟，模拟单独标识 | JSON样例不是真实平台接入 |
| 录制 | 实际文件可打开，时长/画面/音轨匹配 | 录制按钮或队列完成不够 |
| 直播 | 当前平台房间/输出状态及授权的外部观察 | 本地推流设置不够 |

真实试验按用户要求设置有限时长，准备不计正式时间，局部恢复不重置。结束释放输入，核对原进程及输出状态；不要通过重新选择应用而误启动已退出软件。只删本轮明确的测试素材，保留必要的脱敏指标；源包不包含素材和运行回执。

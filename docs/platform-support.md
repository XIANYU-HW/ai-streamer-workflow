# 支持范围

| 能力 | 源码设计范围 | 当前证据边界 |
|---|---|---|
| Node 核心与 setup | Windows、macOS、Linux；Node 22.12+ | 本机纯逻辑与干净目录检查；CI 配置不等于远端已跑 |
| Electron 舞台源码 | Electron 支持的平台 | 空库/隔离/费用等自动检查；不同设备需验证图形、音频和权限 |
| 系统语音/云语音 | 以应用显示的实际支持项为准 | 不保证每个平台拥有同一声音；云语音需供应商设置 |
| 游戏输入 | 适配器接口 | 没有预装通用游戏控制器；每款游戏与系统单独适配 |
| 直播软件/平台 | 适配器与岗位模板 | 没有自动绕过平台限制或保证所有平台实时弹幕可用 |
| AI 客户端/API | 能力接口与提示词 | 没有强制指定模型；客户端无工具/视觉能力时须补接入 |

源码交付不是已签名桌面安装器。`npm run setup` 下载匹配本机的 Electron 依赖，然后 `npm run studio` 从源码启动。不同操作系统的实际声音、捕获、游戏与公开推流尚需对应设备验收。

离线 demo 无模型请求、无真实音频、无游戏、无直播。它只验证调度契约。平台事件、游戏驱动及模型接口配置完成之前，doctor 和报告应保留 UNCONFIGURED / NOT_VERIFIED。

# AI 舞台工作室公开候选版

独立桌面工作室，用于创建角色、声线、场景和经确认的角色记忆。首次启动是空库：没有角色、图片、场景、历史场次或记忆；AI 驱动、服务和语音模型均未选择。启动不会自动调用模型、生成声音、打开麦克风或开始直播。

## 安装与使用

需要 Node.js 22.12 或更新版本及 npm。Electron 固定为 45.0.0。

```sh
npm ci
npm start
```

安装阶段的 `prepare` 只检查源码语法和本地资源引用，不启动应用。可以先创建角色或先创建场景，再把角色加入场景。角色使用用户提供的图片或中性几何占位头像。场次保存当时的角色与场景快照；用户记录的事件可形成记忆草稿，确认后才进入角色记忆。应用本身不选择 AI，也不自动生成角色对话。

## 资料与备份

应用名称为 `AiStreamerStudioPublic`，标识为 `local.ai-streamer.studio.public`，默认资料目录是系统 AppData 下的 `AiStreamerStudioPublic`。可设置 `AI_STREAMER_STUDIO_DATA_DIR`，但必须使用绝对路径，末级目录名为 `AiStreamerStudioPublic` 或 `AiStreamerStudioPublic-*`。

应用拒绝旧工作室目录、指向旧目录的别名，以及已有内容但缺少本应用标记的目录。没有自动寻找旧资料或自动迁移入口；导入仅由用户显式选择符合当前公开版格式的备份。角色、场景及记忆可保存、导出和恢复。

持久密钥由 Electron safeStorage 保存在本应用自己的目录中；仅本次使用的密钥只在内存中。备份不携带密钥或付费许可。Windows 的实际凭据保护能力尚未实机验证。不要分享运行目录或其中的访问凭据文件。

## 可选声音服务与费用

系统声音由用户主动刷新和选择。MiniMax 是可选服务：用户选择服务、填写自己的密钥，并为实时合成显式选择模型。自定义声线根据当前角色的描述、风格和试听文本生成，没有预置个人声线。

付费默认关闭，预算上限为 0。仅保存密钥不会授权费用；用户需在本机设置中启用付费并设置有限的累计美元上限，外部运行接口不能开启它。请求发出前记录预算预留；未知结果保留预留并阻止继续付费，缺失账本也不会自动重置额度。导入资料和修改预算不会清零已记录费用。没有自动充值、订阅或自动付费重试。

费用数据是预算估算，不是供应商账单。未知费用的人工对账界面尚未实现，因此未知结果会保持阻断，不能把它当作零费用继续请求。真实供应商计费、声线质量和可听见的延迟尚未在本公开候选版中验证。

## 节目输出与运行接口

显式启动后，本机服务使用动态分配的 loopback 端口。当前访问地址和控制、生产者、监控令牌保存在本应用自己的 `runtime-access.json`，正常退出时移除；该文件不能提交到仓库或随备份分发。控制权租约、提示截止时间、角色快照及停止回执由运行接口管理，模型配置和调用由外部运行组件明确提供。

`/scene-output.html` 与 `/overlay.html` 提供只读节目画面，公开投影包含显示所需的外观与字幕，不包含角色私密背景和记忆。应用不直接开启平台直播或录制。

## 验证与构建

```sh
npm test
npm run prepare
npm run smoke
npm run build:mac
npm run build:win
```

`test` 使用隔离资料与模拟服务。`smoke` 才会显式启动隐藏的 Electron 窗口，在临时公开版目录中验证空库、创建角色和场景、渲染角色、未选模型及默认费用锁，结束后清理该临时目录。可用 `AI_STREAMER_ELECTRON_BINARY` 指定已安装的测试运行库。

当前 18 项离线测试、静态检查及 macOS 隐藏源码启动检查通过；独立窄审没有剩余重要阻断。整套源码的验证范围见根目录 `docs/verification-status.md`。源码启动通过不等于安装包启动或直播验收通过。

构建脚本只在对应目标系统上复制已安装的运行库与明确列出的源码，不启动成品，也不覆盖已有输出。输出位于 `dist/`。macOS 构建只修改主包身份，helper bundle 标识仍来自 Electron；成品未做有效的开发者签名或公证。Windows 输出是未签名的便携目录。实际打包后启动、Windows 实机、真实声音、账单和直播均尚未验证。
